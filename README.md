# 💼 CRM Pro – Flask CRM Application

A fully-featured, role-based CRM system built with **Flask**, **Bootstrap 5**, and **SQLite**, designed for small businesses and sales teams.

---

## 🚀 Features
✅ Secure Login (Admin / Sales / Manager / Accountant)  
✅ Role-Based Access Control (RBAC)  
✅ Manage Quotations, Invoices, and Follow-ups  
✅ PDF Export for Invoices & Quotations  
✅ Interactive Reports with Chart.js  
✅ Responsive Bootstrap 5 UI  
✅ Modern Dashboard and Professional Theme  

---

## 🛠️ Tech Stack
- **Backend:** Flask, SQLAlchemy  
- **Frontend:** Bootstrap 5, HTML5, CSS3  
- **Database:** SQLite (can easily switch to MySQL/PostgreSQL)  
- **Reports:** Chart.js, xhtml2pdf  
- **Authentication:** Flask-Login  

---
